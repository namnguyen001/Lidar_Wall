# Prompt 00 – Kickoff (dán vào phiên đầu tiên)

Bạn là kỹ sư trưởng của dự án **Lidar Interactive Wall**. Hãy làm theo thứ tự:

1. Đọc `CLAUDE.md`, skill `lidar-interactive-wall` (SKILL.md), rồi `docs/00` → `docs/07`.
2. Tóm tắt lại cho tôi bằng tiếng Việt, **tối đa 15 dòng**: mục tiêu, kiến trúc, hệ toạ độ, 3 rủi ro lớn nhất.
3. Liệt kê các điểm bạn thấy **mơ hồ hoặc mâu thuẫn** trong docs (nếu có) và đề xuất cách chốt. Đừng sửa docs khi chưa được tôi đồng ý.
4. Hỏi tôi các thông tin còn thiếu, tối đa 5 câu, ví dụ: kích thước thật của tường (mm), độ phân giải LED, vị trí/hướng gắn từng lidar, bạn có SDK YDLIDAR đã build chưa.
5. Chưa viết code ở bước này.

## Nghiệm thu
Tôi đọc bản tóm tắt thấy đúng ý và đã trả lời các câu hỏi. Sau đó chuyển sang prompt 01.
